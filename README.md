# Vekin Website

Front-end Next.js site for Vekin — immersive sustainability showcase.

## Summary
- Next.js (app router) + Tailwind CSS
- Interactive DAP carousel and page segments

## Development

Prerequisites:
- Node.js 18+ and npm

Install:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
npm run start
```

## Notes
- Carousel and segment components are in `app/components/DAPLitePageSegments`.
- Public assets live in `public/`.
